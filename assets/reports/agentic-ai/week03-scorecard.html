BIOEE 7600-103 · Week 3 · Finger Lakes Vegetation Survey rescue

The scorecard, cell by cell

Three agent runs cleaned the same survey files. For each of 14 known problems in those files, every run gets one of five verdicts. This page explains what a verdict means, how each run came out, and why each row is scored the way it is.

How to read a cell

Every cell answers two separate questions. Did the run handle the problem correctly? And did it tell you about it? "Told you" means the problem appears in the run's report, decision log or questions list. A comment buried in the code does not count.

Told you
Did not tell you
Handled right
flagged, right

The best outcome. Correct, and you can see what it did.

right, silent

Correct, but you would only know by checking yourself.

Handled wrong
wrong, flagged

A mistake, but written down, so a person reading the notes can catch and fix it.

silent break

The one that matters. The data are wrong and nothing says so. This becomes the dataset.

A fifth verdict, not reached, means the run never worked with that part of the data.

The headline on the slide, "two silent breaks in 42 calls", is 14 problems × 3 runs = 42 cells, of which two are silent breaks.

The three runs

A

The plain task: clean the files, write a short report. Nothing about documentation.

8 flagged, right3 right, silent1 wrong, flagged1 silent break1 not reached

R

The same task plus a block asking for reproducibility: a decision log, flagged questions instead of guesses, a data dictionary, tests. Written in Python.

8 flagged, right5 right, silent1 wrong, flagged

R-rep

Exactly R's prompt, run a second time as a replicate. It chose to write R code instead of Python.

8 flagged, right3 right, silent2 wrong, flagged1 silent break

So the prompt did not change how often a run got things right (8 of 14 flagged-right for all three). What separates them is where they went wrong, and whether it was written down. R is the only run with no silent break.

What to take from it

  • Both silent breaks are about which plant is which (rows 9 and 14). Arithmetic and file formats went fine; taxonomy is where to check first.
  • The reproducibility prompt did not raise the hit rate. A, R and R-rep each got 8 of 14 flagged-right. R is the only run with no silent break, but R-rep had the same prompt and still made one.
  • Replicates differ. R and R-rep had the identical prompt and landed on different verdicts in 8 of the 14 rows, including one silent break.
  • The key was wrong in three places (rows 1, 3, 10) and missed row 14 entirely. Every one of those was found because an agent's output disagreed with us and we went back to the raw files or the field sheets.

The answer key was written before any run and corrected afterwards in dated notes; the corrections are marked on this page. Verdicts come from three separate audit agents, spot-checked by hand. Course page: benninglab.org/teaching/agentic-ai.
